# Quick Start: Rebuilding Context

If you're in a new Claude session and need to rebuild context quickly, use one of these prompts:

---

## For Resume Requests

```
Read CLAUDE.md for my portfolio context.

I need a resume for [COMPANY] - [ROLE TITLE].

Here's the job description:
[PASTE JOB DESCRIPTION]

Save to .resumes/ directory. Use light print-friendly colors.
```

---

## For App Development

```
Read CLAUDE.md for my portfolio context.

I'm continuing work on the PAIP Agentic AI Recruiting System.

[DESCRIBE WHAT YOU WANT TO BUILD/FIX]
```

---

## For LinkedIn Posts

```
Read CLAUDE.md for my context and style preferences.

I want to write a LinkedIn post about [TOPIC].

Keep it authentic, measured, and encouraging. No excessive emojis.
```

---

## For Session Audit

```
Read CLAUDE.md and .claude/SESSION-TRACKING.md.

Please audit this session and create a session audit file.
```

---
